# Udabyte Homebrew tap

Apps by [Udabyte](https://udabyte.com) for [Homebrew](https://brew.sh).

## DeskCloset

A Mac app that files your Desktop and Downloads into plain folders and reminds you before documents
expire. Free to use; every Pro feature is free for 14 days.

    brew install --cask udabyte/tap/deskcloset

Website: https://deskcloset.com · Support: https://deskcloset.com/support

To remove it, press "Deactivate on this Mac" in Settings › DeskCloset Pro first if you have a licence
key, then:

    brew uninstall --cask deskcloset
